En GRAU BARCELONA DIAGONAL S.L. Creemos en una web para todos. Por eso, trabajamos continuamente para garantizar que cualquier persona, independientemente de sus capacidades, pueda navegar, entender e interactuar con nuestro sitio web de manera efectiva, cómoda y sin barreras.

Esta declaración de accesibilidad se aplica al sitio web: joieriagrau.com

Compromiso con la accesibilidad

Nuestro compromiso se basa en los principios fundamentales de igualdad, inclusión y usabilidad. Hemos adoptado medidas técnicas, funcionales y organizativas que nos permiten acercarnos progresivamente al cumplimiento de las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1 en su nivel de conformidad AA, establecidas por el World Wide Web Consortium (W3C), así como a lo dispuesto en el Real Decreto 1112/2018 sobre accesibilidad de los sitios web y aplicaciones móviles del sector público (normativa española aplicable también a entidades privadas que ofrecen servicios al público).

Estado de cumplimiento

Actualmente, este sitio web es parcialmente conforme con los requisitos de accesibilidad de la norma WCAG 2.1 nivel AA, debido a algunas limitaciones que detallamos más abajo y que están siendo abordadas progresivamente por nuestro equipo técnico.

Medidas adoptadas para mejorar la accesibilidad

Para lograr una navegación accesible en joieriagrau.com, hemos incorporado las siguientes medidas:

Diseño responsive que permite la correcta visualización en ordenadores, móviles y tablets.

Contraste adecuado entre texto y fondo para facilitar la lectura.

Navegación mediante teclado sin necesidad de ratón.

Etiquetas alternativas (alt text) en imágenes significativas.

Jerarquía clara de encabezados (H1, H2, H3…) para estructurar los contenidos.

Uso de roles ARIA y etiquetas semánticas HTML5 para facilitar la interpretación por parte de tecnologías de asistencia.

Evitar el uso exclusivo de color para transmitir información.

Tiempos adecuados para la lectura e interacción con elementos dinámicos.

Contenido no accesible

A pesar de nuestros esfuerzos, somos conscientes de que pueden existir ciertos elementos no totalmente accesibles:

Posibles fallos puntuales en contrastes de color, etiquetas, estructura semántica o foco del teclado.

Algunos enlaces no tienen nombres reconocibles.

Algunas listas no contienen únicamente elementos <li> y elementos que admiten secuencias de comandos (<script> y <template>).

Algunos elementos de lista (<li>) no están incluidos dentro de elementos superiores <ul>, <ol> o <menu>.

Estamos trabajando para resolver estos problemas lo antes posible y mejorar la accesibilidad de manera continua.
